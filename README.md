## Overview

Study notes for the [AWS Certified Cloud Practitioner](https://aws.amazon.com/certification/certified-cloud-practitioner)
exam (CLF-C02), published as a static site in English and Portuguese, with light and dark themes. The notes follow the
domains of the official exam guide and link to the AWS documentation of every service they cover.

The site is built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com). The notes live in
`src/content/en-US.ts` and `src/content/pt-BR.ts`, with the same topics and sections in both languages. The build fails
when the two languages diverge. English is served at the root of the site and Portuguese under `/pt-br/`.

The notes for the next certification,
[AWS Certified Solutions Architect - Associate](https://gustavofreze.github.io/aws-certified-solutions-architect-associate/),
follow the same format.

### Topics

- Fundamentals: cloud computing, global infrastructure, access and the Well-Architected Framework.
- Services: storage, databases, compute, analytics, governance, financial management, application integration,
  security, networking, AI and machine learning, migration and the other services in scope for the exam.
- Support and study material: support plans, exam guide, articles, courses and practice exams.

### Study tools

- Search across every note, in both languages, generated by [Pagefind](https://pagefind.app).
- A review page with flash cards. The reader can mark a card as known and hide the known cards. The progress is kept in
  the browser only.

## Installation

Every Node and pnpm command runs inside a Docker container, so the host needs only Docker and GNU Make.

### Repository

To clone the repository using the command line, run:

```bash
git clone https://github.com/gustavofreze/aws-certified-cloud-practitioner.git
```

### Configuration

To install project dependencies locally, run:

```bash
make configure
```

To start the development server with live reload, run:

```bash
make start
```

To stop the development server, run:

```bash
make stop
```

### Build

Build the static site and its search index into `dist/`:

```bash
make build
```

Serve the built site, search included, on the development port:

```bash
make preview
```

Draw the link-preview card into `public/og-image.png`:

```bash
make og-image
```

### Tests

Run the unit tests:

```bash
make tests
```

Check the script every built page ships against its budget of 4000 bytes (run after `make build`):

```bash
make budgets
```

### Review

Run the linter, the formatter check and the Astro and TypeScript checks:

```bash
make review
```

Apply the linter and formatter fixes:

```bash
make fix-review
```

### Reports

Open the development server in the browser:

```bash
make show-site
```

Show outdated direct dependencies:

```bash
make show-outdated
```

### Maintenance

Remove dependencies and generated artifacts:

```bash
make clean
```

> You can check other available commands by running `make help`.
